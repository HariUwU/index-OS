Optional UI sounds: add your own files here before source setup, or under
~/.local/share/index/assets/sounds/ui/ before running index-setup:

  notify.wav      notification arrives
  tick.wav        volume / brightness change
  connect.wav     device or network connected
  disconnect.wav  device or network disconnected
  menu.wav        menu opens
  error.wav       critical notification

The original UI sound effects are included. Short (<300ms) wavs work best for
personal overrides. Missing effects can fall back to the lock-screen sounds.
