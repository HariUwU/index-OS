Drop your own UI sounds here to override the defaults:

  notify.wav      notification arrives
  tick.wav        volume / brightness change
  connect.wav     device or network connected
  disconnect.wav  device or network disconnected
  menu.wav        menu opens
  error.wav       critical notification

Short (<300ms) wavs work best. Anything missing falls back to the
lock screen's existing sounds, so you can add them one at a time.
