# Changelog

## 1.0.0

First stable release of the KDE Plasma 6 / KWin desktop.

- INDEX taskbar, workspaces, Quick Settings, clipboard history and Fastfetch logo.
- Matching lock screen and optional boot login screen.
- Component installer with keyboard selection and a review before installation.
- Optional personal intro video and login music, with file paths shown during setup.
- Intro video settings and once-per-boot login playback.
- Original wallpaper, artwork, sound effects and modified Universal font included.
- Signed pacman repository and source installer for Arch-based Linux.

The AUR recipe is prepared; AUR publication is pending account access.
Tested in an Arch VirtualBox VM. VM video stutter and hardware-specific behaviour
may differ on a physical machine.
