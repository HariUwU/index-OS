## Third-party material

**Perfect DOS VGA 437** — by Zeh Fernando. The base pixel font.
The `-Ext` and `-Universal` builds in `assets/` extend it with extra
scripts; the original font's terms still apply to the glyphs it
contributed. https://laemeur.sourceforge.net/fonts/

**Other bundled fonts** — `MotivaSans-Regular.ttf`, `norwester.otf`,
`gallant12x22.ttf` ship under their own licences. Check each before
redistributing.

**Ark Pixel Font** — optional CJK fallback, installed from the AUR,
not bundled. OFL-1.1. https://github.com/TakWolf/ark-pixel-font

**Project Moon** — *Limbus Company* and *The House of Spiders: The
Index* are the property of Project Moon. This is an unaffiliated fan
project. No game assets are redistributed here.

**Prescript word bank** — generated locally by
`tools/prescript-convert.py` from a source file you supply. The
generated `prescript.json` is gitignored and not distributed.
